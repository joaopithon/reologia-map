## 2. Divisão de trabalho entre as cinco obras

As obras não se sobrepõem; cada uma resolve um problema visual diferente do livro:

- **Netter → correção.** Toda figura anatômica nossa é conferida contra Netter antes de fechar. Ele não define o enquadramento; define o que está certo.
- **Sobotta → profundidade.** Sempre que a figura precisar mostrar *em que camada o gel está*, o modelo é a sequência de dissecção do Sobotta: mesma vista, pele removida, depois SMAS, depois periósteo. É exatamente a gramática do Cap. 20 (superficial → SMAS → profundo → supraperiostal).
- **A Face → recorte.** Define as fronteiras das regiões que o livro nomeia (olheira, malar, zigoma, pré-jowl, têmpora...). Sem um recorte consistente, o Mapa Reológico Facial (§10.2 do documento mestre) não fecha graficamente.
- **Preenchimento Global da Face → gesto clínico.** Referência de como desenhar agulha/cânula, vetor, plano e bolus na mesma figura — e das zonas de risco vascular que **toda** figura de região nossa é obrigada a carregar.
- **Anatomy of Facial Expression → movimento.** Referência das sequências em quadros (repouso → sorriso → mastigação → fala) que o Cap. 7 exige.

## 4. Como redesenhar sem infringir

1. **Nunca recortar/escanear.** Nenhum pixel das cinco obras entra em `ebook/ilustracoes*.json`. A figura é redesenhada, como já foi feito com as ilustrações 1–6 hoje integradas.
2. **Referência cruzada obrigatória.** Toda figura anatômica é conferida em **duas** obras (regra irmã da "regra das três fontes" do §6.4 do documento mestre). Discordância entre elas vira nota de rodapé, não escolha silenciosa.
3. **A figura precisa carregar informação nossa.** Se um desenho não acrescenta plano de injeção, classe reológica, número do banco ou regra de segurança, ele é cópia de atlas e não deve existir no livro — os atlas já fazem isso melhor.
4. **Estilo único.** Traço de linha, paleta das 5 classes, mesma tipografia de rótulo em todas as pranchas. As obras são referência de conteúdo, nunca de estilo — estilos misturados denunciam a origem.
5. **Crédito.** As cinco obras entram na bibliografia como referência anatômica consultada; nenhuma é creditada como fonte de imagem, porque nenhuma imagem delas é usada.
6. **Nenhum número vem daqui.** Vale o mesmo princípio da auditoria de imagens: valores reológicos saem exclusivamente de `data/reologia_produtos_full.json`. Estes livros dão anatomia, não dados.
